### Highlights:
- 🎬 **[Easy Edits Pro (EEP)](https://zvirox.in/projects/eep/):** Linux desktop video editor with 440 shipped commands, 7 workspaces, a CLI, and an MCP server. Features a Rust-owned transactional project model and GStreamer rendering.
- 🎙️ **[Audio Labs Pro (ALP)](https://zvirox.in/projects/alp/):** Linux audio workstation for multitrack recording and editing. Features offline local AI voice tools, CLAP/LV2 plugin hosting, and a 14-tool MCP server.
- 📹 **[Screen Studio Pro (SSP)](https://zvirox.in/projects/ssp/):** Planned Wayland screen recorder for Linux with a frosted-glass UI, PipeWire capture, webcam picture-in-picture, and hardware-first encoding.
- 📺 **[Your TV Friend (YTF)](https://zvirox.in/projects/ytf/):** Non-destructive Android TV debloater and customizable launcher (*Your UI*) with reversible ADB package controls, 5 visual themes, 26 languages, and 297 tested device profiles.

## 🔒 Philosophy: Local-First & Zero Telemetry

- **No Cloud Dependency:** Media editing and audio DSP run entirely on your local hardware.
- **Zero Telemetry:** No tracking beacons, user analytics, or mandatory account logins.
- **Agent-Ready:** First-party MCP servers allow AI coding agents to control editing pipelines via structured tool calls.
- **Built in Public:** Solo maintainer project developed with transparent git histories and honest status badges.
